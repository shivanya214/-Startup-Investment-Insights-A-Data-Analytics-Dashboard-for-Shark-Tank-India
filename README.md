# -Startup-Investment-Insights-A-Data-Analytics-Dashboard-for-Shark-Tank-India
An interactive data analytics dashboard built using Python, Streamlit, Pandas, and Seaborn to analyze startup investments from Shark Tank, providing insights into investor behavior, industry trends, and funding patterns.
A Streamlit-based data visualization dashboard that explores Shark Tank startup data to analyze investments, equity deals, investor participation, and industry-wise funding trends.
Python dashboard for analyzing Shark Tank startup investments using interactive visualizations and data analytics
